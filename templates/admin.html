🤖 Automatic Mode Settings

Configure automatic fan control based on temperature prediction.

🌡️ Fan turns ON when predicted temperature ≥ this value
❄️ Fan turns OFF when temperature drops below this value
⚠️ Important: Automatic mode has NO runtime limit. The fan continues to run until the temperature drops below the deactivation threshold.

ℹ️ How It Works:

  • Manual Mode: Immediately turns fan ON/OFF. Optionally auto-off after specified minutes.
  • Automatic Mode: Monitors predicted temperature and controls fan based on thresholds. No time limit.
  • Priority: Manual control takes priority when active.
  • Fan Off Behavior: When fan is OFF, automatic mode is still monitoring and will activate if conditions are met.
